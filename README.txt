SHERWIN BONAVENTE — PORTFOLIO WEBSITE

This is a ready-to-publish static portfolio website. It uses only HTML, CSS, JavaScript, and local images.

FREE HOSTING OPTION: GITHUB PAGES
1. Create a free account at github.com if you don't already have one.
2. Create a new PUBLIC repository named: sherwin-portfolio
3. Upload everything inside this folder, including the assets folder.
4. In the repository, open Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. GitHub will give you a public website address.

IMPORTANT:
- Keep the assets folder beside index.html.
- Your main contact email is currently bonaventesherwin@gmail.com.
- If you want to change text/email, edit index.html.
